# Nextflow Summit 2026 한국어 안내

Nextflow Ambassador가 제작한 한국어 커뮤니티 홍보 페이지입니다. 행사 소개와 한국 시간 기준 전체 프로그램, 공식 등록 링크를 제공합니다. 공식 사이트는 아래 출처에서 확인할 수 있습니다.

https://jhlee0637.github.io/nextflow-summit-website-kr/

- 행사 소개: https://summit.nextflow.io/2026/virtual/overview
- 전체 프로그램: https://summit.nextflow.io/2026/virtual/agenda
- 브랜드 가이드: https://brand.seqera.io/

최신 행사 정보는 공식 사이트를 확인하세요.

## 로컬 실행

Python 3가 설치된 환경에서 저장소 폴더로 이동한 뒤 실행합니다.

```bash
python3 -m http.server 8765
```

브라우저에서 http://localhost:8765 를 엽니다. 별도의 설치나 빌드 과정은 필요하지 않습니다.
